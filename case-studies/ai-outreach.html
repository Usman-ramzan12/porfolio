The Problem

Web design agencies spend hours doing manual prospecting

Web design agencies selling to local SMBs face the same problem: finding businesses that genuinely need a website, building a compelling first touchpoint, and following up consistently, is a full-time manual job. Most agencies skip it, or pay a human to do it slowly.

The brief: design a system that handles the entire prospecting-to-outreach pipeline autonomously, only targeting businesses with a public email address (so outreach is permissible and relevant), and package it so client agencies can run it themselves without deep technical knowledge.

What I Built

System components

🔍

Prospect Discovery

Queries Google Maps data for local businesses in a target niche/location, filters to those without a website, and verifies a public email is available before adding to the queue.

🤖

Claude-Powered Site Generation

For each prospect, Claude generates a complete, on-brand preview website, tailored to the business's name, type, and location. No templates; each site is unique.

🌐

GHL Hosting & Contact Creation

The generated site is published inside GoHighLevel and a contact record is created for the business owner, linking the prospect's profile to their preview site.

📧

Personalised Outreach

A personalised cold email is sent with a link to the business's unique preview site. The email is generated by Claude, not a template, with the business name and niche woven in naturally.

🔁

Automated Follow-Up Sequences

GHL workflows handle timed follow-ups, day 3, day 7, day 14, so no lead goes cold without a second or third touchpoint, all without human intervention.

🛠️

Reusable Claude Skill + SOP

Packaged as a Claude skill so any authorised user can trigger the pipeline with a single command. Accompanied by a human-readable SOP document so clients can operate it independently.

Hard Problems Solved

What makes this non-trivial

Running unattended within a usage budget

Generating a full website per prospect is expensive if the pipeline runs unconstrained. The system enforces a daily cap (~5 sites/day per client) and tracks Claude API usage per run, stopping cleanly before hitting limits, so clients can leave it running without surprise bills.

Only targeting businesses with public emails

Cold outreach to businesses is permissible and relevant when the email is publicly listed on a directory or their Google Maps profile. The discovery step verifies this before adding a prospect to the queue, no guessing, no scraped lists, no compliance risk.

Making it transferable to non-technical clients

A Claude skill that only I can operate isn't a product. The system was packaged with a written SOP (what the skill does, what inputs it needs, what to check when it runs), so agency clients can trigger and monitor it themselves without understanding the underlying Claude skill architecture.

Outcome
